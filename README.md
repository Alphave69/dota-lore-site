# Лор героев Dota 2 — фанатский сайт

**Сайт:** https://alphave69.github.io/dota-lore-site/

Все 127 героев: связи по лору, народные прозвища, роли по матчам, ролики способностей
и «Мир Доты» — карта вселенной с туманом, осколками прошлого, эпохами и катсценами глав I–III.

- Официальные биографии героев — на [dota2.com](https://www.dota2.com/heroes) (на странице каждого героя есть ссылка).
- Пересказы лора — своими словами по [Dota 2 Вики](https://dota2.fandom.com/ru/) (CC BY-SA) и биографиям героев.
- Карта мира и фон главной — свой арт, сделан в Blender. Портреты и ролики героев загружаются с серверов Valve.
- Статистика ролей — [OpenDota](https://www.opendota.com/).

Фанатский проект, не связан с Valve Corporation. Dota 2 — товарный знак Valve.
